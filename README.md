# 한 걸음 | Daily Fit App

작은 행동을 기록하고 목표를 10단계로 나누어 성취감을 쌓는 다이어트·운동 습관 관리 웹 MVP입니다.

## 기능
- 자동 추천 모드: 식단, 운동, 건강한 생활 목표 추천
- 수동 설정 모드: 목표 이름, 작은 행동, 기간 직접 설정
- 10단계 성취 시스템: 30일 목표는 1, 3, 6, 9, 12, 16, 20, 24, 27, 30일 기준
- 일일 체크인, 진행률, 단계별 칭찬
- 목표 추가·수정·삭제
- 사용자 피드백 및 희망 유료 가격 작성·복사
- 모바일 반응형 웹 화면

## 실행 및 배포
빌드 도구 없이 `index.html`을 브라우저에서 열 수 있습니다. 공개 주소를 만들려면 저장소의 **Settings → Pages**에서 배포 소스를 설정하세요. GitHub Pages 주소는 `https://seriluna.github.io/daily-fit-app/` 입니다.

## MVP의 제한
- 기록은 현재 브라우저의 `localStorage`에 저장되며 계정·서버·기기 간 동기화는 없습니다.
- 피드백은 자동 전송되지 않습니다. 작성한 내용을 복사해 직접 전달합니다.
- 브라우저 데이터를 지우면 기록이 삭제될 수 있습니다. 테스트 중 사이트 데이터를 지우지 마세요.
- 수요 검증용 프로토타입이며 의료·영양 처방을 제공하지 않습니다.

## 다음 검증 단계
1. 직접 목표 생성과 체크인 흐름 테스트
2. 5~10명에게 사용하게 한 뒤 7일 뒤 재방문과 불편함 확인
3. 실제 피드백을 바탕으로 개선 우선순위 결정
